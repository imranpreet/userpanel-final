## Main Route Pages:

- **LoginPage** - User authentication
- **HomePage** - Landing page with galleries and exhibitions
- **MyInformationDashboard** - User dashboard with My Orders, Profile, Payment Settings
- **MyAccount** - Account management
- **MyAddress** - Address management
- **MyPurchases** - Purchase history
- **AllArtworks** - Complete artwork catalog
- **ArtworkGallery** - Individual artwork details
- **ExhibitionsPage** - All exhibitions
- **CheckoutPage** - Cart checkout

## Key Components:

- **Header** - Navigation header
- **Footer** - Page footer
- **FeaturedArtists** - Artists showcase
- **BestsellerProducts** - Best selling artworks
- **GalleriesSection** - Galleries listing
- **CollectionsSection** - Collections management
